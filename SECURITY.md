# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

**Do NOT open a public issue.**

Email: 6ixwave@users.noreply.github.com
or use GitHub's private vulnerability reporting:
Settings -> Security -> Private vulnerability reporting (enable in repo settings).

Response time: < 72 hours.

## Scope

- In scope: log parsing, CLI, wheel install
- Out of scope: GitHub Actions CI (managed by GitHub), Pages (static HTML)

## What we do

1. Acknowledge within 72 h
2. Patch in < 14 days (or coordinate)
3. Public advisory + credit (optional)
